# All Star Bulk Order Block v1.1.10

Impeccable-style visual polish for the ASBO artwork workflow using All Star Embroidery’s existing brand palette.

## Artwork customer experience

- Keeps the v1.1.9 artwork upload/review workflow intact while restyling the customer-facing Artwork section.
- Uses All Star navy, a more muted warm gold, white, and quiet neutral surfaces.
- Removes the heavier shadow/card treatment and replaces it with a cleaner hierarchy, restrained gold accent, and softer dividers.
- Makes artwork status the focal point without turning it into an alarming warning.
- Simplifies attached-file rows and review history so they read as part of the order page rather than separate cards.
- Improves field focus states and mobile spacing while preserving the existing upload controls.

## WooCommerce admin artwork review

- Restyles the existing ASBO Artwork Review metabox without replacing WooCommerce order management.
- Reduces nested cards and competing borders by combining Submitted Artwork and Review Details into one coherent review surface.
- Uses navy for the primary approval action and reserves green/red primarily for meaningful status feedback.
- Uses warm gold as a restrained accent for stitch guidance, focus states, timeline markers, and Request Changes controls.
- Improves file preview rows, typography, review timeline, action area hierarchy, and responsive stacking.
- Keeps the panel visually compatible with WooCommerce admin rather than turning the order editor into a separate branded application.

## Preserved behavior

This is a visual/UX-only release. Artwork uploads, protected file storage, artwork statuses, review history, approval/change-request logic, customer/admin emails, WooCommerce Order Notes, pricing, Supplier Sync, bulk tiers, cart totals, shipping, and checkout behavior are unchanged.
